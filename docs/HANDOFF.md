## 2. このセッションでやったこと

### 2.1 昇格ワーカー経路の実機確認（完了）

実行にあたって、ハーネス側のバグが 3 件見つかった（いずれも修正済み）。
**4 回試して 4 回とも通らなかった前セッションの原因はこれ。**

1. `.e2e/run-elevated.ps1` の既定デバイスが `'\.\PhysicalDrive1'`
   （バックスラッシュ 1 個）で、`devices.find(d => d.id === explicit)` に
   一致せず必ず `exit 2` になっていた。既定を「自動選択」に変えた
2. 同ファイルのログが二重変換で壊れていた。PS 5.1 が npx の UTF-8 出力を
   OEM コードページ (932) で読むため、`Out-File -Encoding utf8` に届く前に化ける。
   `[Console]::OutputEncoding` を UTF-8 に固定した
3. `scripts/e2e-worker-usb.mts` の受信ソケットに `error` ハンドラが無く、
   ワーカー終了時の RST で**未処理例外でプロセスごと落ちて**いた。
   `[done]` の直後に死ぬので、読み戻し検証に一度も到達できなかった。
   GUI 本体 (`write-supervisor.ts:146`) には元からハンドラがあり無事だった
   ——「GUI と同じ経路を通す」はずのテストが GUI より脆かった

## 3. 残っている作業

### 3.1 4 巡目の未修正分（優先度順）

生き延びた 63 件のうち、このセッションで直したのは critical 3 + high/medium の
主要なもの。**残りは未着手**。特に次の塊が大きい:

- **テストと検証スクリプト自体の欠陥**（high 7 件）。
  `e2e-verify-usb.mts` が廃止済みプレースホルダを要求して**正しく書けた USB を
  必ず失敗と報告する**、`if (!gpt) return` が集計と `process.exit(1)` を飛ばして
  **失敗を exit 0 にする**、`e2e-matrix.mts` が ISO 無しなら 0 回まわして緑、
  `.e2e/full-run2.mjs` の check が `|| true` で常に成功 ——
  「検証しているつもりで検証していない」系
- **renderer**（high 5 件）。Error Boundary が無い、UserStep の正規化で
  複数値フィールドがキーボード入力できない、プロファイルを開くと series が
  ISO と無関係に上書きされる、GPU スイッチが 25.10 で解除不能、
  モーダルの focus 奪取
- **media**（high 2 件）。切り詰められた ISO を受け入れて CIDATA が重なった GPT を
  「検証成功」で書く、`bus: 'unknown'` の内蔵ディスクが候補に出る
- **スキーマ**（high 2 件）。`schema.test.ts` が `additionalProperties: true` のまま
  検証していて、そのリリースに無いキーを一切検出できない
- 未検証のまま消えた 58 件の精査（`docs/research` を使って一次資料から確認する）
