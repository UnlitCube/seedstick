answered with sources. **It is not legal advice.** No professional freedom-to-operate (FTO)
search has been made. Last reviewed: 2026-10-20.

libraries into the image (with the default toolset: libappindicator, libindicator — GPL-3.0 —,
libgconf, libnotify, libXss, libXtst). Their notices and sources are not covered yet, so Linux
is shipped as a `.deb` only, which uses the system's libraries.

Files in this repository that are **not** under the MIT license:

- [`docs/research/schema/`](research/schema/README.md) — unmodified subiquity JSON schemas

  ([`docs/research/SOURCES.md`](research/SOURCES.md)); the copies are not included.
- [`docs/research/iso-probe/`](research/iso-probe/) holds data read from the official Ubuntu

## Trademarks

- Seedstick is an independent project. **It is not affiliated with, endorsed by, or sponsored
  by Canonical Ltd.** Ubuntu and Canonical are registered trademarks of Canonical Ltd.
- The product name does not contain "Ubuntu" (or "-buntu"), the repository and website URLs do
  not contain it, and the Ubuntu logo, the "Circle of Friends" and Ubuntu Orange (#E95420) are
  not used. "Ubuntu" appears only to say what the tool works with (nominative use), following
  [Canonical's IP rights policy](https://ubuntu.com/legal/intellectual-property-policy).
- The project was renamed before release (formerly "Autoinstall USB Creator"), because that
  name combined Canonical's feature name *autoinstall* with *usb-creator*, the package name of
  Ubuntu's own Startup Disk Creator, and could be read as an official tool.
- "autoinstall" is not among Canonical's listed trademarks. On USPTO, `AUTOINSTALL` (Reg.
  2276900) is cancelled; `AUTOINSTALL SSL` (Reg. 4626451) is live but covers SSL certificate
  software. Seedstick uses "autoinstall" only as a lowercase descriptive term.
- Seedstick does **not** distribute Ubuntu images. The user downloads the official ISO; the tool
  modifies a copy on the user's own USB drive. **A USB drive or `.img` made by Seedstick is a
  modified Ubuntu image: use it yourself or inside your organisation, but do not redistribute it
  to others** — Canonical's policy does not allow redistributing modified images under the
  Ubuntu trademarks. The app shows this notice when saving an image.
- Windows is a trademark of the Microsoft group of companies. Apple and macOS are trademarks of
  Apple Inc. NVIDIA and CUDA are trademarks of NVIDIA Corporation. Other names are trademarks of
  their respective owners. They are mentioned only to describe compatibility.
- Not checked: the Japanese (J-PlatPat) and EU (EUIPO / TMview) trademark databases for
  "Seedstick" — to be checked by the maintainer before wider promotion.

## Patents

No patent that is still in force was found for the techniques Seedstick uses. This is a search
result, not a guarantee.

- **FAT long file names (VFAT / LFN).** Seedstick writes FAT12/16/32 with long file names
  (`user-data`, `meta-data` do not fit 8.3). Microsoft's LFN patents have all expired:
  US 5,579,517 (2013-11-26), US 5,758,352 and US 6,286,013 (2013-04-01), US 5,745,902
  (2015-04-28); EP 0 618 540 (2014-03-31); JP 4077047 (by 2014-04-01, secondary source).
  Dates were computed from the USPTO publications under MPEP 2701.
- **exFAT is not used** and will not be added (several exFAT patents run until 2027–2028, and
  cloud-init's NoCloud does not read exFAT anyway).
- ISO 9660 (1988), Joliet (1995), El Torito (1995), Rock Ridge (1994), GPT, MBR, CRC-32, MD5,
  SHA-512 (US 6,829,355 released royalty-free by the US government), and SHA-crypt (public
  domain) are all older than 20 years or royalty-free.
- **H.264 / AAC.** Electron's default FFmpeg contains H.264 and AAC decoders, whose patents
  are partly still in force. Seedstick does not play media, so the packages replace FFmpeg with
  Electron's official build without proprietary codecs
  ([`apps/desktop/scripts/after-pack.cjs`](../apps/desktop/scripts/after-pack.cjs), used by both
  the application and the Windows installer builds). CI fails if the application's FFmpeg is
  identical to Electron's default build on Windows, macOS or Linux; the installer's own runtime
  goes through the same hook but is not checked separately.
- Prior art for the overall approach is public and older: Rufus (kernel arguments inserted into
  `grub.cfg` since 2019, `md5sum.txt` updated in place since 2020), Ventoy (cloud-init
  auto-install, 2021), cloud-localds (`cidata` vfat seed, 2012), isohybrid, implantisomd5 (2008),
  Raspberry Pi Imager (FAT with LFN + cloud-init, 2021–2022), and per-machine values passed as
  kernel arguments from a boot menu (USENIX LISA 2000, Agrawala et al.).

Where to check the numbers above: trademark registrations in USPTO
[TSDR](https://tsdr.uspto.gov/) (search by registration number), patents on
[Google Patents](https://patents.google.com/) or [Espacenet](https://worldwide.espacenet.com/),
and the prior-art dates in the public release histories of
[Rufus](https://github.com/pbatard/rufus/releases),
[Ventoy](https://github.com/ventoy/Ventoy/releases),
[cloud-utils](https://github.com/canonical/cloud-utils) (cloud-localds) and
[Raspberry Pi Imager](https://github.com/raspberrypi/rpi-imager/releases).
